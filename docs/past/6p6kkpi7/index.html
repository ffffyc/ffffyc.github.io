题解：P17821 回層浮 / kaisou

2026-10-30 洛谷原文

$\text{Link}$

半年前的联考题，似乎没有在 OI 中见过这种维护特殊函数的李超树题？

题意#

给定正整数 $n,m$ 以及整数序列 $x_{1\sim n},c_{1\sim n},t_{1\sim m}$，你需要选出 $1\sim n$ 的一个非空子序列 $p_{1\sim k+1}$，满足 $p_1=1$，$p_{k+1}=n$ 且 $p_i< p_{i+1}$，最大化 $$\sum_{i=1}^k\sum_{j=1}^m|x_{p_{i+1}}-x_{p_{i}}-t_j|-\sum_{i=1}^{k+1}c_{p_i}.$$

$n,m\le3\times10^5$。

题解#

直接 DP，转移方程即为 $$f_i=\max_{j=1}^{i-1}f_j+w(x_i-x_j)-c_i.$$

其中 $w(x)=\sum_{j=1}^m|x-t_j|$，是一个凸函数。

对于 $x_i$ 单调的部分分，存在决策单调性，可以用二分队列维护，时间复杂度 $O(n\log n\log m)$。

对于 $n\le3\times10^4$ 的部分分，可以进行 CDQ 分治，分治过程对 $x_i$ 排序，计算左半至右半的贡献可采用二分队列或决策单调性分治，时间复杂度 $O(n\log^2n\log m)$。

对于 $m=1$ 的部分分，我们可以将 $|x-t|$ 视作 $\max(x-t,t-x)$，由于这与我们的取 $\max$ 方向相同，可以直接变为两类转移，用李超线段树维护，时间复杂度 $O(n\log n)$。

对于 $m$ 更大的情况，同样可以通过李超线段树进行维护。思考李超线段树的结构：我们事实上只要求任意两个函数的大小关系最多改变一次。此题中函数为 $w(x-x_i)+c_i$，为同一个凸函数的平移，是满足这个条件的。

单次求 $w(x)$ 可以在 $t_j$ 里面二分，做到 $O(\log m)$，李超线段树只需要对出现过的 $x_i$ 建，结点数量 $O(n)$，总时间复杂度为 $O(n\log n\log m)$。
