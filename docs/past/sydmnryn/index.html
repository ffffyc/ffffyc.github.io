题解 UVA10110 【Light, more light】

2020-09-18 洛谷原文

UVA10110 Light, more light#

传送门

思路#

循环输入，直到输入为 $0$ 。

每次判断一下这个数是否为完全平方数，输出即可。

用一个整形数 $w$ 存下 $sqrt(x)$（整形才可把不是完全平方数的平方根的尾数省略），如果 $w*w=x$ 说明 $x$ 是完全平方数（因为它拥有一个因数是它的平方根） 。

在下面我的程序中，直接使用字符串保存并换行，再输出。

下面给出AC代码：

#include<bits/stdc++.h>
using namespace std;
#define int long long
inline int read(){//快读
	char ch=getchar();
	int x=0,f=1;
	while(ch<'0'||ch>'9'){if(ch=='-') f=-1;ch=getchar();}
	while(ch>='0'&&ch<='9') x=x*10+(ch^48),ch=getchar();
	return x*f;
}
signed main(){
	while(1){
		int x=read();
		if(!x){
		    break;
		}
		string a=pow((int)sqrt(x),2)==x?"yes\n":"no\n";//直接换行
		cout<<a;
	}
}
