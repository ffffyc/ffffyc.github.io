2020-09-04 洛谷原文

UVA483 Word Scramble

传送门

看到各位$dalao$都用栈、$stringstream$，本蒟蒻瑟瑟发抖地用了最低级的方法。

思路

每次输入一个字符串，把它倒序输出，再读入下一个字符，直接输出就行了（字符串会自动读入到空格、Tab、回车停止）。

上AC代码~

#include<bits/stdc++.h>
using namespace std;
int main(){
	string a;
	char c;
    while(cin>>a){//读入到文件结尾
        for(int i=a.size()-1;i>=0;i--)	cout<<a[i];//倒序输出
        c=getchar();
        cout<<c;
    }
    return 0;
}
